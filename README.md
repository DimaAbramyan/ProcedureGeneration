# Процедурная генерация комнат с использованием шума

Курсовая работа по теме процедурной генерации игровых уровней.

## О проекте

Проект охватывает полный цикл генерации: от создания исходного шума до отрисовки финального уровня со связанными комнатами и физически корректными коридорами.

## Управление

В проекте есть всего 2 ракурса: от первого лица и сверху. Для их смены нажмите кнопку **Change POV**.

**От первого лица:**
- `WASD` — перемещение по плоскости
- `Пробел` — прыжок
- `Alt` (зажать) — игнорировать мышку

**Сверху:**
- `WASD` — перемещение камеры по плоскости
- `ПКМ` (зажать) + движение вверх/вниз — приближение и отдаление камеры

## Меню настроек

- **SEED** — отвечает за сид генерации
- **Size (0, 4096)** — размер карты (рекомендуется использовать значения, кратные степени двойки или хотя бы делимые на 8; не рекомендуется превышать 3500 px)
- **Generate Texture** — генерирует текстуру
- **From color (0, 1)** — яркость цвета, от которого учитываются тайлы для построения комнат
- **To color (0, 1)** — яркость цвета, до которого учитываются тайлы для построения комнат
- **CellSize (0, 1)** — рудимент, ни на что не влияет
- **Percent (0, 1)** — рудимент, ни на что не влияет
- **CorridorPercent (0, 1)** — насыщенность коридоров, соединяющих комнаты (0 — минимальный граф, соединяющий все комнаты; 1 — максимальный граф коридоров)
- **Generate Floor** — запуск генерации уровня
- **x1, x2 ... x16** — изменение приближения камеры при виде сверху
- **Change POV** — переключение активной камеры

## Технологии

- **Движок:** Unity
- **Язык:** C#
- **Шейдеры:** ShaderLab, HLSL

## Возможности

- Генерация карты комнат на основе шума
- Фильтрация комнат по настраиваемым параметрам
- Построение коридоров между комнатами с учётом физической корректности
- Многопоточная генерация для ускорения вычислений
- Настраиваемые параметры генерации через интерфейс
- Управление камерой для навигации по уровню
